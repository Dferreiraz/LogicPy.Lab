## 💻 Sobre o projeto

O **LogicPy.Lab** é um laboratório de estudos dedicado à lógica de programação e aos fundamentos da linguagem Python.

O projeto reúne scripts e aplicações executadas via terminal (CLI), desenvolvidos para transformar conceitos teóricos em soluções práticas. Os exercícios abordam desde estruturas condicionais e laços de repetição até manipulação de dados, criação de funções e desenvolvimento de pequenos sistemas interativos.

A proposta é consolidar os fundamentos da programação por meio de projetos progressivos, desenvolvendo o raciocínio lógico e construindo uma base sólida para aplicações mais complexas.

### 🎯 Objetivos do projeto

- Desenvolver o raciocínio lógico e a capacidade de resolver problemas.
- Praticar os fundamentos da linguagem Python.
- Compreender estruturas condicionais e laços de repetição.
- Trabalhar com strings, listas, dicionários e funções.
- Desenvolver aplicações interativas executadas pelo terminal.
- Aplicar validações de entrada e regras de negócio.
- Explorar a organização e a legibilidade do código com boas práticas de programação.
- Registrar a evolução dos estudos por meio de projetos práticos.

## 🚀 Projetos

O laboratório reúne diferentes projetos, cada um com foco em conceitos específicos da programação.

| Projeto | Conceitos principais | Como executar |
|---|---|---|
| **Guessing Game** | Laços `while`, condicionais, números aleatórios e validação de entradas. | `python guessing-game/main.py` |
| **Password Manager** | Manipulação de strings, dicionários, funções e conceitos básicos de segurança. | `python password-manager/main.py` |
| **ATM Simulator** | Regras de negócio, controle de saldo, estruturas condicionais e formatação de valores monetários. | `python atm/main.py` |
| **Tic-Tac-Toe** | Listas, algoritmos de vitória, controle de turnos e lógica de jogo. | `python tic-tac-toe/main.py` |

## 🧠 Conceitos praticados

Ao longo dos projetos, o laboratório aborda fundamentos importantes da programação.

**Lógica de programação**

- Variáveis e tipos de dados.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (`if`, `elif` e `else`).
- Laços de repetição (`for` e `while`).
- Funções, parâmetros e valores de retorno.
- Validação de entradas e tratamento de situações inesperadas.

**Python e manipulação de dados**

- Manipulação de strings.
- Listas e dicionários.
- Geração de números aleatórios.
- Formatação de textos e valores monetários.
- Importação e utilização de módulos.
- Organização e reutilização de código.

**Desenvolvimento de aplicações CLI**

- Entrada de dados pelo terminal.
- Exibição de informações ao usuário.
- Criação de menus interativos.
- Controle de estado de uma aplicação.
- Implementação de regras de negócio.
- Desenvolvimento de jogos e simuladores.

## 🛠 Tecnologias

As seguintes tecnologias e ferramentas são utilizadas no desenvolvimento dos projetos.

## ⚡ Pré-requisitos

Antes de executar os projetos, certifique-se de ter o Python 3 instalado em sua máquina.

Verifique a instalação com o comando:

```bash
python --version
```

Em alguns sistemas, pode ser necessário utilizar:

```bash
python3 --version
```

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Dferreiraz/LogicPy.Lab.git
```

### 2. Entre na pasta do projeto

```bash
cd LogicPy.Lab
```

### 3. Abra o projeto no Visual Studio Code

```bash
code .
```

### 4. Execute um dos projetos

Escolha o projeto desejado e execute o arquivo principal pelo terminal.

Por exemplo, para iniciar o Guessing Game:

```bash
python guessing-game/main.py
```

Para executar o Tic-Tac-Toe:

```bash
python tic-tac-toe/main.py
```

> **Observação:** dependendo do sistema operacional e da instalação do Python, utilize `python3` no lugar de `python`. Os comandos pressupõem que os arquivos estejam organizados conforme a estrutura indicada neste README.
